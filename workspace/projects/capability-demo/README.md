# 能力验证 Demo — AI 数字员工任务筛选器

## 目的
验证 AI 幕僚长的实际动手能力，而非空谈。通过一个真实可运行的工具，演示：
- **任务拆解**：把抽象目标拆成可执行步骤
- **文件产出**：创建真实可用的 Python 工具
- **运行验证**：实际执行并确认逻辑正确
- **问题排查**：遇到环境问题能定位根因并解决

## 工具内容
`task_filter.py` — 根据老板「AI 数字员工平台」的三大筛选标准，判断一个任务是否适合做成数字员工：

1. **高重复 + 强规则**（有固定 SOP，不需创造判断）
2. **可量化 + ROI 一眼算清**（处理量/工时/错误率）
3. **低信任成本 + 可人工兜底**（出错代价低，能一键接管）

## 运行方式
```bash
python task_filter.py        # 输出判定结果
python task_filter.py --json # 输出结构化 JSON
```

## 验证结果（逻辑正确）
| 任务 | 总分/3 | 判定 |
|------|--------|------|
| 财务票据录入 | 2.71 | ✅ 非常适合 → AI数字员工 |
| 销售成交 | 1.3 | ❌ 不合适 → 保留人工 |
| 库存对账 | 2.5 | ✅ 非常适合 → AI数字员工 |
| 复杂客服投诉 | 1.35 | ❌ 不合适 → 保留人工 |

> 结论完全符合老板「任务工厂」定位：高重复+强规则+可兜底的任务才值得做数字员工。

## 排查记录（环境问题）
运行中发现 Windows Git Bash 控制台对 **UTF-8 中文输出不兼容**（中文 stdout 被静默丢弃，导致命令无显示）。
- 排查过程：ASCII 输出正常 → 中文 print 无输出 → 中文脚本文件运行无显示 → 确认是控制台显示层问题
- 解决方案：脚本逻辑本身 100% 正常（exit 0，输出文件完整 1021 字节）；用 ASCII 版本验证逻辑；中文输出写入文件持久化
- 经验：本机执行 python 脚本时，如需中文输出建议重定向到文件，或使用 ASCII 输出

## 文件
- `task_filter.py` — 中文版（功能完整）
- `task_filter_ascii.py` — ASCII 版（控制台友好，验证逻辑用）
- `output.txt` — 中文版实际运行输出
