## 二、结论：最廉价方案

### 🏆 外部 API 最优解：**火山引擎/豆包语音合成大模型**
- 价格 **≈0.2 元/万字符**，为国内主流大厂最低
- 抖音同款音色，仿真人/情感表达效果好
- 有免费额度，适合快速验证
- 量大可谈更低单价

### 🆓 零成本自托管：**GPT-SoVITS**（开源）
- 完全免 API 调用费，可克隆任意音色
- 契合"开源和本地模型优先"原则
- 需要 GPU（或 CPU 慢速），有部署成本
- 适合长期/私有化场景

## 四、推荐路径
1. **快速验证**：用火山引擎/豆包 API（0.2元/万字符）
2. **规模化降本**：接入本地 GPT-SoVITS，调用费归零
3. **多供应商兜底**：Provider 可插拔，随时切换阿里云/讯飞
