# AI数字员工平台 — 30天 MVP 计划（project_manager 测试产出）

## 目标
30天内跑通"任务工厂"MVP：用户能用自然语言配置一个任务，数字员工定时/触发执行，结果交人工复核。

## 里程碑

### M1（Day 1-7）：任务配置器
- [ ] 自然语言教任务（LLM解析规则）
- [ ] 模板库（3个预置模板：数据录入/报表生成/工单分诊）
- **依赖**：DeepSeek API 接入（Day 1-2）
- **交付物**：可配置一个"数据录入"任务的界面
- **风险**：LLM解析不稳定 → 兜底：结构化表单+模板

### M2（Day 8-16）：数字员工执行器
- [ ] 定时触发（APScheduler）
- [ ] 多步工作流（LangGraph）
- [ ] 出错自愈 + 全程留痕
- **依赖**：M1 的配置产物可直接执行
- **交付物**：配置好的任务能自动跑起来
- **风险**：工作流编排复杂度 → 先做线性单流程

### M3（Day 17-23）：人工复核台
- [ ] 一键通过/修改/驳回
- [ ] 关键操作强制确认
- **依赖**：M2 产生真实执行结果
- **交付物**：复核台可操作
- **风险**：操作流不清晰 → 复用审批组件

### M4（Day 24-30）：Dogfooding 自用
- [ ] 内部跑通 3 个真实任务
- [ ] 收集使用反馈，修复关键问题
- **交付物**：可演示的 MVP
- **风险**：自用场景选错 → 选数据录入最稳

## 关键路径
M1 → M2 → M3 → M4（严格串行，M2是核心风险点）

## 里程碑交付物清单
1. 可配置任务的 UI（M1）
2. 自动执行的数字员工（M2）
3. 人工复核台（M3）
4. 完整 dogfooding 演示（M4）
