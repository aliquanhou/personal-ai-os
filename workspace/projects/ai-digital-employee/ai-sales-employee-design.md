# AI 销售员工 — 产品方案设计

> 定位：AI数字员工平台的第一个垂直切入场景
> 原则：快速验证优先、不重复造轮子、先做产品后做平台、ROI导向
> 协同：复用 Personal AI OS 长期记忆系统（核心差异化）

---

## 一、为什么选"销售"作为第一个数字员工

### 1.1 痛点最痛、ROI最可量化
| 岗位 | 可量化指标 | 痛点强度 | 付费意愿 |
|------|-----------|---------|---------|
| 客服 | 响应时长、解决率 | 中 | 中（已有成熟方案竞争） |
| **销售/线索跟进** | **触达量、转化率、成交额** | **高** | **高（直接关联收入）** |
| 数据录入 | 处理量、错误率 | 中 | 低 |

**关键洞察**：销售是唯一"直接创造收入"的岗位。老板对"多接一单活"的感知远强于"省一个人力成本"。销售数字员工的价值**可以直接用增加的GMV来算账**，这是最强的销售话术。

### 1.2 长期记忆在这里价值最大
销售的本质是**客户关系和跟进历史**：
- 客户说过什么偏好？上次聊到哪了？承诺过什么？
- 谁跟进了？跟了几次？结果如何？
- 竞品动态、价格敏感度、决策链关系

**没有记忆的销售工具 = 每次重头再来**。这正是 Personal AI OS 记忆系统最能发力的地方，也是与大厂通用方案、垂直SaaS差异化的核心。

### 1.3 市场验证充分
- 销售线索跟进是中小企业真实高频需求
- 现有工具（CRM）只记录不"干活"，AI销售要"主动干活"
- 可对标：探马、尘锋（有客户但AI弱）、大厂（通用不垂直）

## 二、产品定位

### 2.1 一句话定位
> **"AI销售员工" = 一个会记住每个客户、自动跟进线索、帮销售签单的数字员工。**

### 2.2 目标客户
- **优先**：B2B中小企业（有销售团队但线索跟进效率低）
- **首选行业**：SaaS/软件、企业服务、教育培训、B2B批发
- **画像**：有5-50人销售团队，线索量>跟进能力，老板愿意为"多成交"付费

### 2.3 不做的事（避免过度工程化）
- ❌ 不做通用"AI销售大脑"
- ❌ 不做复杂CRM（用现成CRM集成，如销售易/纷享销客/钉钉CRM）
- ❌ 不碰预测成交概率等玄学模型
- ✅ 只做"能记住 + 能跟进 + 能算账"的最小闭环

## 三、核心能力设计（MVP范围）

### 3.1 三大核心能力
```
┌─────────────────────────────────────────────┐
│  AI销售员工                                   │
│                                              │
│  ① 记忆客户   ② 自动跟进   ③ 销售助手        │
│     (长期记忆)  (线索培育)   (话术/报价/复盘)  │
│                                              │
│  底层：Personal AI OS 记忆 + DeepSeek        │
│  编排：LangGraph/Dify + MCP(企微/钉钉/CRM)    │
└─────────────────────────────────────────────┘
```

### 3.2 能力①：记忆客户（差异化核心）
- **客户画像**：自动从对话/资料中提取并沉淀客户信息（行业、规模、痛点、预算、决策链）
- **跟进历史**：完整记录每次触达（时间、渠道、内容、客户反应）
- **偏好记忆**：记住客户的沟通偏好、关注点、承诺事项
- **知识库**：沉淀销售话术、产品资料、常见异议处理
- **技术**：复用 Personal AI OS 记忆系统，向量化 + 结构化

### 3.3 能力②：自动跟进线索
- **线索分级**：根据意向度自动给线索打标签（热/温/冷）
- **自动触达**：对温线索自动发跟进消息（企微/钉钉/短信），话术由AI生成
- **定时提醒**：到点提醒销售"该跟进X客户了"
- **SOP执行**：按预设跟进节奏（如3/7/15天）自动执行培育流程
- **技术**：LangGraph 编排 + MCP 接入企微/钉钉

### 3.4 能力③：销售助手
- **话术生成**：根据客户画像和场景生成个性化话术
- **异议处理**：实时回答"客户说太贵了怎么办"
- **报价辅助**：根据客户预算和产品组合推荐报价
- **跟进复盘**：每次跟进后自动生成复盘，沉淀到记忆

### 3.5 MVP范围界定（先少后多）
**MVP只做**：①记忆客户 + ②自动跟进（温线索培育）+ ③话术助手
**MVP不做**：报价系统、预测模型、复杂CRM、多团队协同

## 四、技术架构

### 4.1 复用 vs 自研（严格执行"不重复造轮子"）
| 模块 | 方案 | 说明 |
|------|------|------|
| Agent编排 | LangGraph / Dify | 集成，不自研 |
| 模型 | DeepSeek 本地/API | 主力 |
| 向量库 | Chroma / pgvector | 现成 |
| 消息渠道 | MCP → 企微/钉钉/短信 | 标准协议 |
| CRM集成 | 销售易/纷享/钉钉CRM API | 现成 |
| **长期记忆** | **Personal AI OS（自研复用）** | **核心差异化，唯一自研** |

### 4.2 参考架构
```
┌──────────────────────────────────────────────┐
│  业务层：线索分级/自动跟进/SOP/话术/复盘       │
├──────────────────────────────────────────────┤
│  记忆层：客户画像/跟进历史/偏好/知识库(向量)    │
│         ← Personal AI OS 记忆系统             │
├──────────────────────────────────────────────┤
│  Agent层：LangGraph 编排跟进流程               │
├──────────────────────────────────────────────┤
│  模型层：DeepSeek（话术/分类/总结/生成）        │
├──────────────────────────────────────────────┤
│  集成层：MCP → 企微/钉钉/短信 + CRM API        │
└──────────────────────────────────────────────┘
```

## 五、商业模式

### 5.1 定价（按岗位订阅，ROI导向）
- **基础版**：AI销售员工（记忆+跟进+话术）¥999/月
- **专业版**：+ 私有化部署 + 多场景 ¥2999/月
- **定制版**：深度定制 + 服务 ¥3万+/年

### 5.2 ROI话术（核心销售武器）
> "您一个销售月薪8000，能跟10个有效线索；
> AI销售员工¥999/月，能同时跟进100个线索，且不离职不遗忘。
> 多成交一单，就回本。"

### 5.3 收入结构
- 订阅制（核心，毛利>80%）
- 私有化部署实施费（一次性）
- 增值服务（行业话术包、培训）

## 六、90天验证计划

### 阶段1（第1-30天）：MVP + 客户访谈
- 搭建MVP：记忆客户 + 自动跟进 + 话术助手
- 找3-5家B2B中小企业老板访谈，验证付费意愿
- **关键问题**：您愿意为"自动跟进线索的AI员工"每月付多少钱？

### 阶段2（第31-60天）：付费试点
- 打磨ROI量化能力（帮客户算"多赚/省了多少"）
- 跑通1-2个付费试点，真实跟进线索
- 收集"记忆是否成为选择理由"的反馈

### 阶段3（第61-90天）：迭代 + 验证核心假设
- 基于试点反馈迭代产品
- **核心验证点**：老板是否愿意按月续费？
- 若续费率>70%，可规模化；否则调整

### 里程碑
| 时间 | 里程碑 | 通过标准 |
|------|--------|---------|
| 第30天 | 可演示MVP | 3-5家客户访谈，50%表达付费意向 |
| 第60天 | 付费试点 | 1-2家真实付费，跑通跟进闭环 |
| 第90天 | 验证 | 续费意向>70%，ROI数据可量化 |

## 七、风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| 大厂通用AI销售挤压 | 高 | 垂直+私有化+记忆差异化 |
| 老板对"AI自动跟客户"信任度低 | 高 | 人工兜底+透明可查+先小规模试点 |
| 自动触达被当骚扰/封号 | 中 | 频率控制+合规话术+渠道合规 |
| 记忆系统幻觉/记错客户 | 中 | 人工确认机制+来源留痕 |
| 与现有项目资源冲突 | 中 | 复用短视频平台底层，明确优先级 |

## 八、与长期愿景的协同

- **Personal AI OS** → 记忆系统是本方案核心差异化，直接复用
- **AI数字员工平台** → 本方案是平台的第一个验证场景，跑通后复制到客服/数据
- **AI短视频平台** → 共享底层（模型/记忆/部署），销售场景可为其获客
- **长期** → 从"AI销售员工"切入，逐步扩展为"AI数字员工平台"，最终服务AI产品公司愿景
