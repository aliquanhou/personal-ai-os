# 📋 CSV报告生成工具 — 详细项目计划

> 基于《CSV报告工具功能规格 v0.1》
> 目标：构建一个轻量、纯标准库的 CSV 报告生成 CLI 工具
> 状态：规划完成，待启动开发

---

## 一、项目概览

### 1.1 产品定位
一个**轻量级 CSV 报告生成工具**，读取 CSV 文件并生成 4 种类型的 Markdown/HTML/TXT 报告。纯 Python 标准库实现，无第三方硬依赖，CLI + 模块导入双入口。

### 1.2 核心价值
- 快速从 CSV 生成可读报告
- 零依赖、易部署、易集成
- 复用已验证的 web_downloader 工具范式

### 1.3 明确不做（范围边界）
- ❌ 图表生成
- ❌ 数据库支持
- ❌ 模板引擎
- ❌ GUI 界面
- ❌ pandas 强绑定

---

## 二、需求规格要点回顾（来自规格 v0.1）

| 维度 | 规格要求 |
|------|---------|
| **输入** | CSV 文件，自动检测编码(UTF-8/GBK)，支持自定义分隔符、表头选项 |
| **报告类型** | summary(概览) / stats(数值统计) / group(分组聚合) / top(Top-N) |
| **入口** | CLI + 模块导入双入口，复用 web_downloader 范式 |
| **输出格式** | md(默认) / html / txt，输出到 stdout 或文件 |
| **异常层次** | ReportError → FileError / ParseError / ConfigError |
| **依赖** | 纯标准库，无第三方硬依赖 |
| **测试** | 覆盖编码检测、异常、分组统计等核心场景 |

### 开放问题（待拍板）
- correlation 报告是否增加
- 多 CSV 合并支持
- HTML 图表
- 白名单机制（**建议加**）

## 三、任务分解（WBS）

### 阶段 0：准备（0.5 天）
- [ ] **T0.1** 搭建项目结构（`tools/`、`tests/`、`docs/`）
- [ ] **T0.2** 确认规格开放问题（白名单等），最终定稿规格 v0.1

### 阶段 1：核心框架（1.5 天）
- [ ] **T1.1** 定义异常层次：`ReportError` → `FileError`/`ParseError`/`ConfigError`
- [ ] **T1.2** 实现 CSV 解析模块：编码自动检测(UTF-8/GBK)、分隔符检测、表头处理
- [ ] **T1.3** 设计报告数据模型与输出接口抽象

### 阶段 2：四种报告类型（3 天）
- [ ] **T2.1** summary 报告：概览（行数、列数、字段列表）
- [ ] **T2.2** stats 报告：数值统计（均值、中位数、最大/最小、标准差）
- [ ] **T2.3** group 报告：分组聚合（按指定列分组、聚合统计）
- [ ] **T2.4** top 报告：Top-N 排行（按数值列排序取前 N）

### 阶段 3：输出渲染（1.5 天）
- [ ] **T3.1** Markdown 渲染器（默认格式）
- [ ] **T3.2** HTML 渲染器
- [ ] **T3.3** TXT 渲染器
- [ ] **T3.4** 输出路由：stdout / 文件写入

### 阶段 4：CLI 与模块接口（1 天）
- [ ] **T4.1** CLI 入口：参数解析（输入文件、报告类型、输出格式、输出路径）
- [ ] **T4.2** 模块导入接口：`generate_report()` 函数封装
- [ ] **T4.3** 复用 web_downloader 范式（双入口、错误处理风格）

### 阶段 5：测试与验证（2 天）
- [ ] **T5.1** 编码检测测试（UTF-8/GBK 样本）
- [ ] **T5.2** 异常处理测试（文件不存在、解析失败、配置错误）
- [ ] **T5.3** 四种报告类型功能测试
- [ ] **T5.4** 分组统计正确性测试
- [ ] **T5.5** 输出格式/路由测试

### 阶段 6：打磨与收尾（1 天）
