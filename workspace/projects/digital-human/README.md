# 数字人口播项目

## 🎯 项目目标

构建一个**数字人口播系统**，通过 AI 技术生成数字人形象进行口播视频生产，面向普通用户/商家实现低成本、可批量化的视频内容生产。

## 🏔️ 与长期愿景的关系

数字人口播是 AI 产品矩阵中的重要一环，与 AI 短视频自动生产平台、AI 数字员工平台共享底层能力（模型/记忆/部署），是 Personal AI OS 生态的组成部分。

## 🚀 核心定位

- **给谁用**：需要批量视频内容的小商家、自媒体创作者
- **解决什么**：真人出镜录制成本高、效率低的问题，用数字人替代口播录制
- **核心价值**：低成本、可批量、稳定产出高质量口播视频

## 🧩 核心能力（规划）

1. **数字人形象**：生成/定制可复用的数字人形象
2. **口播驱动**：文案 → TTS 语音 → 数字人口型/动作驱动
3. **视频合成**：数字人 + 背景 + 字幕 + 素材的自动合成
4. **批量生产**：一条文案一键产出多条口播视频

## 📐 技术方向（待定）

- 数字人驱动：参考开源方案（如 SadTalker / HeyGen 类）评估
- TTS：开源/本地模型优先
- 视频合成：FFmpeg / 模板混剪
