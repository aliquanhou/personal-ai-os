# 🎬 AI短视频自动生产平台

> **定位**：面向中国普通小商家的抖音视频自动生成工具
> **目标**：帮助小商家每天自动生成抖音视频，降低内容生产成本
> **技术栈**：Python, TypeScript, React, FastAPI, DeepSeek

---

## 项目概述

本项目旨在为中国的普通小商家（餐饮、零售、服务等）提供一个AI短视频自动生产平台。核心价值在于：
- **降低门槛**：不懂剪辑、不懂运营的小商家也能每天产出高质量抖音视频
- **自动化**：从素材到成片的全链路自动化
- **本地化**：贴合抖音平台规则和中国市场特性

---

## 核心功能模块

1. **素材管理**：图片/视频素材上传、分类管理
2. **AI文案生成**：基于商品/服务信息自动生成短视频脚本
3. **自动剪辑**：图文/视频混剪、模板化生成
4. **智能配音**：TTS语音合成（普通话/方言）
5. **字幕生成**：自动字幕+关键词高亮
6. **一键发布**：对接抖音开放平台API自动发布
7. **数据反馈**：播放量、互动数据回流优化
