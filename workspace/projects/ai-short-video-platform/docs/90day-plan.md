# 🗓️ 90天执行计划：AI短视频自动生产平台

> **原则**：快速验证 > 完美设计，先做最小可用产品（MVP），用真实用户验证价值

---

## 总体阶段划分

| 阶段 | 时间 | 重点 |
|------|------|------|
| **阶段1：MVP验证** | 第1-30天 | 最小产品+10个种子用户验证 |
| **阶段2：产品打磨** | 第31-60天 | 完善功能+扩展到30-50用户 |
| **阶段3：规模化** | 第61-90天 | 打磨商业化+获客+付费验证 |

---

## 阶段1：MVP验证（第1-30天）

### 目标
- 做出一个能用的最小产品
- 服务10个真实小商家
- 验证"AI自动生成视频"的价值

### 第1-7天：市场调研与种子用户
| 天数 | 任务 | 产出 |
|------|------|------|
| D1-2 | 调研10-20家本地餐饮/零售商家 | 访谈记录、需求清单 |
| D3-4 | 确定MVP功能范围 | MVP功能清单 |
| D5-7 | 招募10个种子用户 | 种子用户名单 |

**种子用户招募渠道**：
- 身边认识的商家朋友
- 本地餐饮微信群
- 美团/抖音上找本地商家私信
- 承诺免费使用+专属服务

### 第8-20天：MVP开发
| 天数 | 任务 | 技术要点 |
|------|------|----------|
| D8-9 | 项目脚手架 | FastAPI + React + PostgreSQL |
| D10-11 | 用户系统+素材管理 | 注册登录、素材上传 |
| D12-14 | AI文案生成 | 接入DeepSeek，行业prompt |
| D15-17 | 视频合成 | FFmpeg模板混剪，TTS配音 |
| D18-19 | 视频预览+手动发布 | 商家确认后手动下载/发布 |
| D20 | 基础数据统计 | 视频生成记录、播放统计 |

### 第21-30天：种子用户测试
| 天数 | 任务 | 产出 |
|------|------|------|
| D21-23 | 部署上线，种子用户使用 | 首个可用版本 |
| D24-27 | 收集反馈，迭代修复 | 反馈记录、问题清单 |
| D28-30 | 评估MVP效果 | 验证报告 |

**验证问题**：
- ❓ 商家是否愿意用？（使用频率）
- ❓ AI生成的视频效果如何？（播放量）
- ❓ 商家愿意付费吗？（付费意愿调查）

---

## 阶段2：产品打磨（第31-60天）

### 目标
- 完善核心功能
- 扩展到30-50个用户
- 验证付费意愿

### 第31-40天：核心功能优化
| 天数 | 任务 |
|------|------|
| D31-33 | 优化AI文案质量（行业prompt调优） |
| D34-36 | 增加行业模板（餐饮/零售/服务） |
| D37-38 | 增加自动发布功能（抖音开放平台API） |
| D39-40 | 增加数据看板（播放/点赞/评论趋势） |

### 第41-50天：扩展用户
| 天数 | 任务 |
|------|------|
| D41-43 | 免费版上线（每周3条，带水印） |
| D44-46 | 抖音内容获客（AI生成教程视频引流） |
| D47-48 | 微信社群运营，种子用户口碑传播 |
| D49-50 | 目标：达到30-50个活跃用户 |

### 第51-60天：付费验证
| 天数 | 任务 |
|------|------|
| D51-53 | 上线付费功能（99元/月标准版） |
| D54-56 | 向种子用户推广付费版 |
| D57-58 | 收集付费反馈，调整定价 |
| D59-60 | 付费转化率评估（目标>5%） |

**关键问题**：
- ❓ 有多少用户愿意付费？
- ❓ 99元/月的定价是否合适？
- ❓ 免费版是否有效引流？

## 资源需求

### 技术资源
- 1名开发者（你自己）
- FastAPI + React + PostgreSQL + FFmpeg + DeepSeek API
- 云服务器（8C16G）+ 对象存储

### 资金预算（90天）
| 项目 | 预算 |
|------|------|
| 云服务器 | ~2,400元 |
| AI API费用 | ~1,000元 |
| 域名+备案 | ~500元 |
| 广告测试 | ~3,000元 |
| **合计** | **~7,000元** |

### 时间投入
- 每天 2-4 小时（业余）或全职
- 核心开发集中在第8-20天

---

## 风险与应对

| 风险 | 应对 |
|------|------|
| 种子用户难找 | 扩大范围，先服务身边商家 |
| AI视频质量差 | 先做模板化，保证基础质量 |
| 用户不付费 | 调整定价，增加免费试用量 |
| 抖音API限制 | 先手动发布，后接API |
| 时间不够 | 严格MVP，砍掉非核心功能 |

---

## 90天后的决策点

**继续 or 放弃 or 调整？**

- ✅ 如果：30+付费用户，留存>50%，播放数据有效
- ➡️ 继续：扩大规模，融资或全职投入
- ⚠️ 如果：付费用户<10，但用户喜欢用
- ➡️ 调整：优化定价/功能，再试30天
- ❌ 如果：用户根本不用，播放量为0
- ➡️ 放弃或大幅转向
