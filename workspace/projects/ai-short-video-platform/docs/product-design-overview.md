# 🎬 AI短视频自动生产平台 — 产品设计总览

> 本文件整合了市场分析、竞争分析、技术方案、商业模式、90天计划的核心结论，
> 并标出需要拍板的关键决策点。

---

## 一、产品一句话定位

**面向中国普通小商家的"AI内容运营官"** —— 每月99-299元，AI帮他们每天自动生成并发布抖音视频。不是又一个视频剪辑工具，而是"自动干活的服务"。

---

## 二、目标用户与痛点

### 核心用户：本地生活小商家
- 餐饮老板（快餐/小吃/奶茶/火锅）
- 零售店主（服装/便利店/水果）
- 服务商家（美容/健身/家政）

### 四大痛点（按优先级）
1. **没时间**做内容（老板身兼数职）
2. **不会**做内容（不知道拍什么、怎么拍）
3. **做了没效果**（拍了没播放量）
4. **无法持续**（坚持不下来）

---

## 三、核心功能（4大模块）

| 模块 | 说明 | MVP优先级 |
|------|------|----------|
| ① AI自动生成抖音视频 | 模板混剪（FFmpeg），非文生视频 | ⭐核心 |
| ② 自动写文案 | DeepSeek生成脚本 | ⭐核心 |
| ③ 自动配音 | TTS（火山/阿里云） | ⭐核心 |
| ④ 自动发布计划 | 定时任务+抖音开放平台API | 二期 |

---

## 四、技术方案要点

### 核心决策：**模板混剪，不做文生视频**
- 文生视频成本高（0.5-3元/条）、质量不稳、有降权风险
- 模板混剪成本低（~0.2元/条）、质量稳定、抖音算法友好
- 流程：商家上传3-5张素材 → AI生成文案+配音+字幕 → 模板合成15-30秒成片

### 技术栈
| 层面 | 技术 |
|------|------|
| 后端 | FastAPI + Python |
| 前端 | React + TypeScript + Vite |
| 数据库 | PostgreSQL + SQLAlchemy |
| 视频处理 | FFmpeg |
| 任务队列 | Celery + Redis |
| AI | DeepSeek API + TTS |
| 存储 | 阿里云OSS / MinIO |

### 单条视频成本
| 项目 | 成本 |
|------|------|
| 文案(DeepSeek) | ~0.01元 |
| 配音(TTS) | ~0.1元 |
| 合成(FFmpeg) | ~0.01元 |
| 存储 | ~0.05元 |
| **合计** | **~0.2元/条** |

## 五、商业模式

### SaaS订阅制（核心）
| 套餐 | 价格 | 权益 | 目标用户 |
|------|------|------|----------|
| 免费版 | ¥0 | 每周3条，带水印 | 引流 |
| 标准版 | ¥99/月 | 每天1条，无水印 | 小微商家 |
| 专业版 | ¥299/月 | 每天3条+数据报告 | 成长商家 |
| 企业版 | ¥999/月 | 多账号+定制模板 | 连锁/品牌 |

### 单位经济
- 标准版：月收入99元，内容成本6元，**毛利率 >90%**
- 回本周期：标准版~2个月

### 北极星指标
**月活跃付费用户数（MAPU）**

## 六、90天计划（核心里程碑）

| 阶段 | 时间 | 重点 |
|------|------|------|
| MVP验证 | 第1-30天 | 最小产品+10个种子用户 |
| 产品打磨 | 第31-60天 | 完善功能+30-50用户+付费验证 |
| 规模化 | 第61-90天 | 商业化+获客+付费 |

| 里程碑 | 验收标准 |
|--------|----------|
| M1 MVP上线(D20) | 能生成1条AI视频 |
| M2 种子用户(D30) | 10个商家各用≥3次 |

| M5 规模化(D90) | 100+注册，30+付费 |

### 90天预算：~7,000元（服务器2400+AI 1000+域名500+广告3000）

## 七、⚠️ 需要老板拍板的关键决策点

> 现有方案已相当完善，但有几个点需要确认后才能动手写代码。

### 决策1：MVP 范围是否聚焦"单条视频生成"？
现有方案MVP包含"文案+配音+合成+预览+手动发布"。
**建议**：MVP先砍掉"自动发布"（抖音API审核+合规成本高），先用"手动下载/手动发布"验证核心价值——商家是否愿意用、AI视频是否有播放量。自动发布放到二期。

### 决策2：切入点行业
方案默认首选**餐饮**（需求最刚性、内容最模板化）。
**建议确认**：是否就锁定餐饮做深，还是先做通用模板快速覆盖？

### 决策3：种子用户从哪来
这是整个90天计划最大的风险点。方案建议"身边商家+本地微信群+私信"。
**建议**：现在就可以开始列10个潜在商家的名单，不要等代码写完。

### 决策4：是否复用 Personal AI OS 底层能力
本方案和AI数字员工平台都依赖 DeepSeek + 记忆 + 部署能力。
**建议确认**：是否要抽一层共享的"AI能力底座"，避免两个项目重复造轮子。
