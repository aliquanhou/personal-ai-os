# 数字人口播项目

## 项目定位

构建一个基于 AI 的数字人口播系统，让用户通过简单配置，即可自动生成由数字人播报的短视频内容。核心价值是**用低成本快速批量生产口播视频**，面向有内容产出需求的个人创作者与商家。

> 定位原则：不做又一个视频剪辑工具，而是"AI 口播内容运营官"——输入文案/主题，自动产出成片。

## 核心能力

1. **文案生成** — 集成大模型（DeepSeek）根据主题/脚本自动生成口播文案
2. **语音合成** — 使用 TTS 将文案转化为自然流畅的语音
3. **数字人形象** — 生成/选择数字人形象，支持自定义形象与动作
4. **口播合成** — 将数字人形象与语音合成，生成最终口播视频（模板混剪）
5. **批量生产** — 支持批量配置，规模化产出

## 技术路线

遵循"集成而非自研"原则：

- **文案生成**：DeepSeek
- **语音合成**：开源 TTS（本地优先）
- **视频合成**：FFmpeg（模板混剪，成本低、质量稳定）
- **数字人**：优先集成现成方案，不做底层自研
- **架构**：模块化设计，各能力独立可调用，便于替换/升级

## 与长期愿景的协同

- 复用 Personal AI OS 的底层能力（模型调用、记忆系统），不重复造轮子
- 与 AI 短视频平台、AI 数字员工共享模型/部署基础
- 快速验证方向，MVP 优先
